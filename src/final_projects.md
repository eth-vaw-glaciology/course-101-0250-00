# Final projects

You will work on the final projects in groups of two. A single GitHub repository is sufficient per project.

!!! warn
    The final project GitHub repository should **remain private** until submission unless you need it to be public for deploying documentation.

Final projects should be handed-in on a single GitHub repository, including scripts, documentation, unit and reference tests, Continuous Integration (CI), instructions to run the software and reproduce the results, and references.

## Topics

Select a project of your choice:

### Multi-physics couplings and scientific tracks

Thermal (T), mechanical (M), and hydrological (H) processes.

1. TH: porous convection
2. TM: free convection
3. TM: shear heating
4. HM: porosity waves
5. Rock mechanics: shear strain localisation
6. Ice sheet mechanics: shallow shelf approximation
7. Fluid dynamics: Navier-Stokes equations
8. Oceanography: shallow water equation
9. Seismic wave physics: elastic wave propagation

## Presentations

For the presentations, prepare a few slides describing your project, model equations, code structure, results, and outlook. The presentation is 10min talk + 5min discussion.
